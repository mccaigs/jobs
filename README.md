# AI Job Intelligence System

Something is happening here.
But it’s not random.

This is an autonomous system that runs twice a day, scanning the UK job market for AI roles, filtering signal from noise, and turning it into something actionable.

---

## What this is

A continuously running AI job discovery and ranking system.

* 06:00 → targeted search (Edinburgh + high-fit roles)
* 12:00 → UK-wide AI job sweep
* Multi-source ingestion (Reed, CWJobs, TotalJobs, LinkedIn, etc.)
* Detects what’s new vs yesterday
* Filters for relevance
* Outputs structured reports you can actually use
